# Simulador de Interés Compuesto

Calculadora web para estimar cuánto crecen tus ahorros con interés compuesto, en **pesos (ARS)** o **dólares (USD)**.

## Funciones

- Capital inicial y aporte mensual
- Tasa nominal anual (TNA) con capitalización mensual
- Ajuste por inflación: muestra el poder de compra real y el rendimiento real anual
- Gráfico año a año con el capital aportado, los intereses y el valor real
- Diseño responsive, optimizado para celular

## Ver online

Una vez activado GitHub Pages, la página queda en:

```
https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/
```

## Tecnologías

- HTML, CSS y JavaScript sin dependencias de build
- [Chart.js](https://www.chartjs.org/) desde CDN

## Aviso

Simulación con fines educativos. Los resultados son estimaciones y no constituyen asesoramiento financiero.
